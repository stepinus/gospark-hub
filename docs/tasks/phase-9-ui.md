# Задача воркера: UI фазы 9 (страница Engines и нативные рецепты)

Читай `docs/tasks/phase-9-engines-native.md` — спецификация API. Ниже только твой кусок.

## Файлы, которые ты создаёшь или меняешь

### `frontend/src/pages/Engines.jsx` (новый)

Страница `/engines`, стиль — как у `pages/Settings.jsx` (те же классы, карточки, отступы).

- Заголовок «Engines» и подзаголовок: движки моделей ставятся один раз на машину, рецепты
  запускаются на них без контейнеров.
- Карточка движка: имя (`TensorFold`), версия (`1.1.1` или «не установлен»), отметка «есть
  обновление до 1.1.1», если `latest != version`.
- Кнопки по состоянию:
  - не установлен → «Установить»;
  - установлен → «Обновить» (disabled, если `latest == version`) и «Удалить» (красная);
  - во время запроса — спиннер/disabled на всех кнопках.
- Удаление — через существующий `components/ConfirmDeleteModal.jsx`: заголовок «Delete engine
  TensorFold?», текст про то, что нативные рецепты на нём перестанут запускаться.
- Ошибки показывать текстом в карточке (`detail` из ответа), не алертом.
- Данные: `GET /api/engines`, действия `POST /api/engines/{name}/install`,
  `POST /api/engines/{name}/update`, `DELETE /api/engines/{name}`. После каждого действия
  перечитать список.

### `frontend/src/lib/api.js`

Добавь четыре функции рядом с существующими (`getEngines`, `installEngine`, `updateEngine`,
`deleteEngine`), используя тот же `request`-хелпер и стиль ошибок, что уже есть в файле.

### `frontend/src/App.jsx`

Маршрут `/engines` и пункт навигации «Engines» для админа — рядом с «Settings».

### `frontend/src/pages/RecipeDetail.jsx`

Нативный рецепт (`recipe.kind === "native"`):

- бейдж «Native» рядом с названием (как бейдж «Локальный»);
- вместо «Install» — ничего (кнопки установки нет вовсе);
- «Launch»/«Stop» работают как раньше — эндпоинты те же;
- блок требований: вместо образа/диска — строка `native.engine` («Engine: tensorfold»),
  путь модели (`native.model`) и порт;
- «Delete» для нативного рецепта не показывает docker-специфичных предупреждений.

Контейнерные рецепты должны выглядеть и вести себя точно как сейчас.

## Проверка

`cd frontend && npm run build` — зелёный. Затем прогони headless-браузер по `http://127.0.0.1:9105`
(логин `r@local.test` / `password123`, инстанс уже запущен):
- `/engines` рисует карточку TensorFold;
- `/app/searxng` (контейнерный) выглядит как раньше;
- консоль без ошибок.

## Чего не делать

- Не трогать Go-код, `internal/`, `cmd/`, `docs/`.
- Не менять общий layout, тему, шрифты, `package.json`.
- Не добавлять зависимостей.

## Готово, когда

`npm run build` зелёный, страница и правки в детали рецепта проверены в браузере, один коммит с
русским сообщением.
